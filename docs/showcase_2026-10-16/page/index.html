Edits that load in the game

Each recolour was made in Hantei-chan's CG manager: export the palette, shift the hue of the costume colours only, import it, and save. Then the game was booted to training. In UNI2 and MBTL the file goes to the UNI2-IM or MBTL-IM mod folder; in MBAACC the bank is saved in place. Line art, shading and skin are untouched.

Tools the other editors don't have

How it was measured

  • The game frames are real captures: the HUD hidden, the stage animation held still, and the fighters hidden for a clean backdrop taken on the same frame.
  • Each editor renders the frame with the same view and zoom. Only the editor's own back buffer is read: no desktop capture and no input.
  • Every render goes through the same model: it's composited over the game's backdrop with the same light, glow and camera alignment.
  • All three editors are scored on the same pixels: everything any of them drew. Scoring each editor only where it drew would reward drawing less.
  • The frames were picked before measuring, from our existing render-test cases.
  • sosfiro's and gonp's drawing code is unchanged. Each got a small capture-only patch that loads the file, picks the frame and reads the image back.
  • "Gonptechan" is the name of our own fork's releases, not a separate tool. gonp's editor is the upstream gonpgonp/Hantei-chan.
