# update/parity-1014 → master

## Summary

This PR replaces #83 (`update/ex-mbac` → `master`, last updated 2026-10-04). `update/parity-1014` contains all of `update/ex-mbac` plus 276 more commits. In total it is 554 commits ahead of `origin/master` (HEAD `736a678`; 2,504 files changed, +546,929 / −6,728 lines).

Since #83 was written, the branch has gained:
- .pat and sprite rendering measured against UNI2 and MBTL game captures;
- PAT editor file safety;
- fixes for UNI2/MBTL/UNIB data loss;
- the CG manager with palettes, a unified CG + .pat texture browser and in-game proofs;

Everything #83 described is still here. The 2026-10-16 release audit (`docs/audit_2026_10_16/RELEASE_AUDIT.md`) is the starting point for this text. Every item it listed as a gap was re-checked against the tree; the ones still open are listed under **Known gaps**.

## Known gaps

- **F21:** the per-game hit-effect and hitstop lists are not started. Every game uses the MBAACC lists (`frame_disp_at.h`, `hitEffectList`/`hitStopList`).
- **D17:** BaseData templates show a banner and greyed fields, but there is no merged-template preview. `MergeTemplatePattern` is used only by tests.
- **Stage character shadows** are not built in the editor. The MBTL path is traced (INDEX round 24, handoff).
- **RBO has no in-game proof.** The in-game check in `docs/formats/pacnyx_parity.md` is still pending.
- **UNIEL** is tested on synthetic data only: no install, no real-data run. The Steam UNI[cl-r] archive is out of scope by user decision.
- **Mouse-driven UI is not hand-tested:** timeline drags, pattern manager, multi-monitor windows, audio output, PNG drag-drop, and the issues listed above.
- **ha6-patch export** in mod projects needs pcmod schema 2. Until then it ships whole files (`hmod_export.cpp`).
- **No licence.** The repo has no LICENSE (`docs/stage3d/SCOPE.md` §2.4 is still a user decision). Zanaylo is credited in code comments and in SCOPE, not in the About box.
- **UNI2 set-991 ring arcs** change between game runs and stay masked in the compare.
- **Flaky tests seen:**
  - `live_reload` failed once in a full run;
  - `texsrc_mbaacc_akiha_cg` failed once in a full run;
  - `ha4_golden` failed under `-j2` next to the suites and passed alone (`docs/audit_2026_10_16/CG_AUDIT.md`).
  - Treat a single failure of any of these under load as unconfirmed until it is re-run alone.
- **Other in-game gaps:**
  - a new UNI2 `_pN.pal` (as opposed to an edited existing palette) has not been shown in game;
  - no runtime fxr shader in-game proof is kept (`docs/cg/FXR_STATUS_2026-10-16.md`, "Not done");
  - the 3D stage MBAACC alignment is checked by test and ini checker, not in MBAACC.
- **Squirrel:** no structured `_cmd_` table editor and no preview simulation (`docs/squirrel/SCOPE.md` P5–P7).
- **3D stages:** no bloom/FXAA/cull fidelity, no every-stage sweep and no editing (SCOPE P1.1, P1.2, P3.1, P4).
